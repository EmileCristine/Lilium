Como fazer um arranjo

em apenas três passos

base

Escolha uma flor dominante para causar impacto, como rosas, tulipas, peônias e etc.

leveza

Adicione um elemento arejado para criar leveza, como eucaliptos, ramos de oliveira e até mesmo gipsofila.

textura

Opcional para ter profundidade e trazer interesse, utilizando elementos como camomila, lisianto ou outras folhafgens delicadas.

dicas

Use menos hastes, permita que haja espaço negativo, mantenha os arranjos ligeiramente assimetricos e evite misturar muitas cores.
